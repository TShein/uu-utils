# JSON Formatter

一个简洁的在线 JSON 格式化工具，浏览器打开即用。

## 功能

- **自动格式化** — 输入 JSON 自动美化
- **树形折叠/展开** — 逐节点或全部展开/折叠
- **美化/压缩切换** — 一键切换两种显示模式
- **一键复制** — 复制格式化后的 JSON 文本
- **精确错误定位** — JSON 语法错误时显示具体行号列号
- **快捷键** — `Ctrl+Enter` 格式化，`Tab` 缩进

## 使用

直接用浏览器打开 `json-formatter.html` 即可，无需安装任何依赖。

## 部署

推送到 GitHub 后，开启 GitHub Pages（Settings → Pages → Source: main branch）即可在线使用。
